# 📚 Projetos e Estudos

Repositório pessoal de estudos e projetos práticos, organizado por disciplina, assunto e tipo de material.

## 📁 Estrutura do Repositório

```
projetos-e-estudos/
├── disciplinas/               # Conteúdos organizados por disciplina
│   ├── programacao/           # Programação
│   │   ├── fundamentos/
│   │   ├── algoritmos-e-estruturas-de-dados/
│   │   └── desenvolvimento-web/
│   ├── matematica/            # Matemática
│   │   ├── algebra/
│   │   └── calculo/
│   ├── ciencias/              # Ciências
│   │   ├── fisica/
│   │   └── quimica/
│   └── linguagens/            # Linguagens
│       ├── ingles/
│       └── portugues/
└── projetos/                  # Projetos práticos independentes
    └── exemplo-projeto/
```

Dentro de cada pasta de **assunto**, os materiais são separados por tipo:

```
<assunto>/
├── resumos/      # Sínteses e resumos do conteúdo
├── anotacoes/    # Anotações de aula ou de leituras
├── exercicios/   # Listas, resoluções e práticas
└── referencias/  # Links, livros e materiais de referência
```

## 📖 Tipos de Material

| Pasta | Descrição |
|---|---|
| `resumos/` | Sínteses objetivas dos conteúdos estudados |
| `anotacoes/` | Anotações livres feitas durante aulas ou leituras |
| `exercicios/` | Exercícios resolvidos, listas e desafios |
| `referencias/` | Links, bibliografias e materiais externos |
| `projetos/` *(raiz)* | Projetos práticos completos e independentes |

## 🗂️ Disciplinas

- [`disciplinas/programacao/`](disciplinas/programacao/README.md) — Lógica, algoritmos, linguagens e desenvolvimento web
- [`disciplinas/matematica/`](disciplinas/matematica/README.md) — Álgebra, cálculo e demais tópicos de matemática
- [`disciplinas/ciencias/`](disciplinas/ciencias/README.md) — Física, química e demais ciências naturais
- [`disciplinas/linguagens/`](disciplinas/linguagens/README.md) — Língua portuguesa, inglês e outras linguagens
- [`projetos/`](projetos/README.md) — Projetos práticos e estudos de caso

## ➕ Como Adicionar Conteúdo

1. Identifique a disciplina e o assunto do material.
2. Navegue até `disciplinas/<disciplina>/<assunto>/`.
3. Coloque o arquivo na subpasta correspondente ao tipo (`resumos/`, `anotacoes/`, `exercicios/` ou `referencias/`).
4. Para novos assuntos, crie a pasta do assunto com as quatro subpastas de tipo.
5. Para novos projetos práticos, crie uma pasta em `projetos/<nome-do-projeto>/` com seu próprio `README.md`.

## 📝 Convenções de Nomenclatura

- Nomes de pasta: **minúsculas**, **sem acentos**, palavras separadas por **hífen** (`-`).
- Nomes de arquivo: **minúsculas**, palavras separadas por **hífen**, com extensão adequada (`.md`, `.py`, `.js`, etc.).
- Exemplo: `disciplinas/programacao/fundamentos/resumos/variaveis-e-tipos.md`
