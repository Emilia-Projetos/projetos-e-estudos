# Exemplo Projeto

> Projeto de exemplo que ilustra a estrutura recomendada para projetos práticos neste repositório.

## Objetivo

Demonstrar como organizar um projeto prático dentro da pasta `projetos/`, com documentação clara e estrutura bem definida.

## Tecnologias

- Markdown

## Como executar

Este é apenas um projeto de referência. Substitua este conteúdo pelas instruções do seu projeto real.

## Aprendizados

- Como estruturar um repositório de estudos
- Boas práticas de documentação com Markdown
