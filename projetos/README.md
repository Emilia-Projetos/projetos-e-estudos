# 🚀 Projetos

Esta pasta contém projetos práticos e estudos de caso desenvolvidos de forma independente.

## Estrutura de cada projeto

Cada projeto possui sua própria pasta com ao menos um `README.md` descrevendo:

- **Objetivo** — O que o projeto faz e o que você quis aprender com ele.
- **Tecnologias** — Linguagens, frameworks e ferramentas utilizadas.
- **Como executar** — Passos para rodar o projeto localmente.
- **Aprendizados** — Principais conceitos e dificuldades encontradas.

## Como adicionar um novo projeto

1. Crie uma pasta em `projetos/<nome-do-projeto>/`.
2. Adicione um `README.md` com objetivo, tecnologias, instruções e aprendizados.
3. Organize os arquivos do projeto dentro da pasta criada.
