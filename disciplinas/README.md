# 🎓 Disciplinas

Esta pasta reúne todos os materiais de estudo, organizados por **disciplina** e **assunto**.

## Estrutura

```
disciplinas/
├── programacao/
├── matematica/
├── ciencias/
└── linguagens/
```

Cada disciplina contém subpastas por assunto. Dentro de cada assunto, os materiais são
separados em quatro tipos:

| Pasta | Conteúdo |
|---|---|
| `resumos/` | Sínteses e resumos do conteúdo |
| `anotacoes/` | Anotações de aulas ou leituras |
| `exercicios/` | Exercícios, listas e resoluções |
| `referencias/` | Links, livros e materiais externos |

## Como adicionar uma nova disciplina

1. Crie uma pasta em `disciplinas/<nome-da-disciplina>/`.
2. Adicione um `README.md` descrevendo a disciplina.
3. Dentro dela, crie subpastas por assunto, cada uma com as quatro pastas de tipo acima.
